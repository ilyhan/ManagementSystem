# ManagementSystem

Добро пожаловать в ManagementSystem. Это простое и удобное приложение позволяет управлять списком задач, разделяя их на выполненные, в работе и невыполненные, а также создавать и обновлять задачи.

## Основные возможности:

- **Добавление новых задач**  
  Нажмите кнопку "Добавить задачу". Откроется модально окно, в котором можно заполнить поля для будущей задачи.
  
- **Управление задачами**  
  - Просмотр всех задач
  - Обновление в модальном окне
  - Управление задачами в рамках одного проекта (представллено в виде канбан доски)

- **Фильтрация и поиск по задачам**  
  Фильтрация осуществляется на странице всех задач. Есть возможность поиска задачи, используя поле для ввода, и фильтрации задачи по статуса и проекту.

## Технологии:

- **TypeScript**
- **React**
- **Tanstak Query**

## Запуск проекта

Для запуска проекта выполните следующие шаги:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ilyhan/ManagementSystem.git
   ```

2. **Перейдите в папку проекта:**
   ```bash
   cd ManagementSystem
   ```

3. **Установите зависимости:**
   ```bash
   npm install
   ```

4. **Запустите приложение:**
   ```bash
   npm run start
   ```
   После выполнения этих команд приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173), и вы сможете работать с ним в браузере.

## Особенности 
1. **Toasts**  
   При возникновении ошибок или успешном действии всплывает окно для уведомления пользователя.

2. **Цвета карточек проекта**  
   Карточки имеют разные цвета в зависимости от приорита выполнения (Low - зеленый, Medium - синий, High - красный)

3. **Адаптивный дизайн**  
   Приложеннием удобно пользоваться как с компьютера, так и с мобильного телефона
